# Necrodice_cli
A CLI dice rolling application for necromunda

type 'help' for a list of accepted inputs
--- Available Necromunda Dice ---
- number: Number Die
- attack: Attack Die
- wound: Wound Die
- damage: Vehicle Damage Die
- location: Vehicle Location Die
- control: Vehicle Control Die
---------------------------------
type 'reroll' to reroll the last input.
